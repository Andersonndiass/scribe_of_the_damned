# Glossário

Termos do jogo em português e latim, com o significado mecânico de cada um. Fonte: `specs/000-game-bible/spec.md` v1.0.

## Termos do jogo

| Termo | Significado mecânico |
|---|---|
| **Atril** | Fila ordenada de letras coletadas; 5 espaços no padrão, até 8 com upgrades. Não pode ser reordenado |
| **Letra** | Coletável que cai dos inimigos. Dura 8s no chão. Pode ser rara (vogal dourada, +50% de poder) ou alvo (anel GOLD) |
| **Letra-alvo** | Letra que continua uma palavra possível no atril atual |
| **Letra corrompida** | Letra da Pena Negra (Cap. 5); dentro de uma palavra, causa heresia automática |
| **Drop ponderado** | Sorteio de letras que favorece as que continuam prefixos possíveis (FR-013) |
| **Dicas** | Lista, no HUD, das palavras ainda possíveis com o prefixo atual |
| **Ímã** | Raio (40px) em que as letras são puxadas até o jogador |
| **Conjurar** | Espaço: consome a palavra válida do atril e dispara o milagre |
| **Milagre** | Efeito de uma palavra; mais forte quanto mais longa. Não tem recarga |
| **Grande Oração** | Palavra de 7–8 letras; milagre muito forte |
| **Heresia** | Conjurar sem palavra válida: stun de 0.5s, poça de aggro de 2s no local do erro e letras perdidas |
| **Purge** | Shift: as letras do atril caem no chão ao redor do jogador para serem recoletadas. Sem custo |
| **Poça de aggro** | Área deixada pela heresia que atrai os inimigos por 2s |
| **Combo** | Duas palavras dentro de 2.5s, em qualquer ordem; substitui o efeito da 2ª |
| **Apócrifos** | FIDES, LUMEN, PURGO, GLORIA e VERBUM; comprados na loja, valem só na partida |
| **Velas** | Vida: 3 no início, até 8. Golpe fraco tira 1, forte tira 2 |
| **Códice** | O livro amaldiçoado; cada capítulo é uma página |
| **Página / arena** | Arena de 640×360; degrada a cada onda |
| **Campeão** | Inimigo raro 1.5× com contorno BLOOD; solta tinta dourada e devolve 1 vela |
| **Tinta dourada** | Moeda da loja; zera ao fim da partida |
| **Scriptorium Noturno** | Loja entre ondas |
| **Travar / Reroll** | Guardar uma carta para a próxima visita / trocar as cartas (5 de tinta, +3 a cada vez) |
| **Telegrafia** | Aviso visual (BLOOD) antes de um spawn ou ataque |
| **Grimório** | Enciclopédia; o único lugar onde o latim é traduzido |
| **Palavras profanas** | XUL, SINGI, XURC, usadas pelo Abade Caído |
| **Codex Completus** | Tela final depois dos 5 chefes |

|---|---|---|---|---|

| PAX | paz | 3 | Base | Onda que empurra e atordoa por 1.5s |
| CRUX | cruz | 4 | Base | Cruz fixa: dano em + e bloqueio de projéteis. Única que bloqueia o XURC |
| VITA | vida | 4 | Base | +1 vela |
| AQUA | água | 4 | Base | Poça de lentidão |
| IGNIS | fogo | 5 | Base | Área de fogo com dano contínuo |
| MORTIS | da morte | 6 | Base | Onda na tela toda (exige atril 6) |
| FIDES | fé | 5 | Apócrifo | Escudo de 1 golpe |
| LUMEN | lume | 5 | Apócrifo | Ímã e letra-alvo reforçados por 10s |
| PURGO | purifico | 5 | Apócrifo | Limpa a tela em lotes; fora de combos |
| GLORIA | glória | 6 | Apócrifo | Milagres reforçados; fora de combos |
